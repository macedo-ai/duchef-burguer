# DuChef Burguer

Landing page / cardápio digital para **DuChef Burguer — Hambúrguer artesanal gourmet**.

## Objetivo

Implementação independente inspirada na arquitetura de experiência do site de referência informado pelo proprietário, com identidade e código próprios.

## Recursos

- Hero responsivo
- Cardápio por categorias
- Carrinho lateral
- Controle de quantidades
- Retirada ou entrega
- Formulário de finalização demonstrativo
- FAQ
- Layout mobile-first/responsivo
- Sem Instagram
- Sem WhatsApp
- Sem cobrança real nesta versão

## Executar

Projeto estático. Abra `index.html` diretamente ou sirva a pasta com qualquer servidor HTTP.

Exemplo:

```bash
npx serve .
```

## Deploy

Compatível com Cloudflare Pages, GitHub Pages, Netlify ou Vercel.

## Observação

Fotos iniciais usam imagens remotas do Unsplash e devem ser substituídas pelas fotografias oficiais da DuChef quando disponíveis.
